# Documentation

- [Reports](reports/): sprint and slice outcomes, including historical
  checkpoints and feasibility work.
- [Architecture](architecture/): proposed designs, options and planning
  estimates; proposals are not necessarily implemented.
- [Investigations](investigations/): experiments, comparisons and analyses
  of technical behavior and limitations.
- [Status](status/): recorded test results and the security overview.

The [delivery plan](../plan.md) describes the current implementation and
planned work. Historical reports describe their original runs and should not
be treated as current results.
