# MeetScribe

MeetScribe is a local, Dockerized meeting assistant in development. It will first transcribe short WAV/MP3 recordings in a browser, then add speaker labels, editable draft minutes, and saved meetings. Audio and transcripts will be processed locally, using only synthetic or explicitly authorized non-sensitive test recordings during development.

**Current status:** The application has not been implemented yet. There are no installation, model-download, run, or test commands to execute. The incremental implementation and review checkpoints are in [plan.md](plan.md).

As each checkpoint becomes runnable, this README will list its verified dependencies and versions, exact model artifacts and download commands, Docker setup and usage, test commands, offline operation, and data handling. No credentials, recordings, or model weights belong in this repository.
